# WOJAKMAXI

Private single-user Solana terminal. Paper copy trading only. Live signing is not connected.

It watches the current top Pump.fun wallets by realized PnL, plus live Axiom fee-wallet swaps and the 24h fomo.family leaderboard. Quotes come from Jupiter. Nothing here sends a transaction.

```bash
npm install
npm run dev
```

The desk listens on port 8080.
